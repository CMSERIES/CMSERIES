# Village Administrative System (VAS)

### Digital Administration for Village Offices

**Village Administrative System (VAS)** is a digital platform designed to modernise and simplify administrative activities in village offices and Dorbar Shnong in Meghalaya.

The system aims to digitise document applications, resident records, certificate generation and administrative operations.

## 1. Project Overview

VAS provides a centralised platform for managing village administrative services, reducing manual paperwork and improving record management.

## 2. Key Features

- Digital Document Application
- Resident Record Management
- Certificate Generation
- Application Tracking
- QR Code Integration
- Document Verification
- Officer and User Management
- Role-Based Access Control
- Audit Logs
- Automatic Database Backup

## 3. Supported Documents

- Residential Certificate
- No Objection Certificate (NOC)
- Character Certificate
- Family Membership Certificate
- Recommendation Letter
- Birth Verification
- Death Verification
- Income Verification
- Land/House Verification
- Permission Letter

## 4. Technology

- Backend: Python Flask
- Frontend: HTML, CSS, JavaScript and Jinja
- Database: SQLite / PostgreSQL
- Interface: Web-Based and Desktop
- Languages: English and Khasi

## 5. Deployment

The system is intended to support:

- Standalone Desktop Deployment
- Local Area Network (LAN) Deployment
- Web-Based Deployment

## 6. Project Status

Development in Progress.

## 7. Project Vision

To promote digital transformation in village administration through accessible, efficient and reliable technology.
